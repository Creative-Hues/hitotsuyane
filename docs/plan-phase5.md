# フェーズ5の計画:各画面のヘルプ

## 結論

- 各タブの一番上の画面の右上に「?」ボタンを置き、押すと下からシート(ヘルプ)を出す
- シートには、その画面の使い方を3〜5個、短い言葉の箇条書きで出す。「人格」は設定した呼び方に置き換える
- 治療(服薬・受診メモ)のヘルプには、医療のアプリではないことと、データは端末の中だけにあることを入れる
- ヘルプの文は、すべて1つのファイル(`src/lib/helpTexts.ts`)にまとめる(あとで文を直しやすくするため)
- データの形は変えない(データベースの版は9のまま)。マージの前に、バックアップのお願いはいらない
- 3つの段階に分ける。テスト版に反映する前と、main にマージする前に止まる
- 決めてほしいことの答えは「決まったこと」の章にある

## 前提

- この計画は、`dev`(1606b59 フェーズ4。main と同じ)のコードを元にしている
- 画面の言葉の「人格」は、今と同じしくみ(`useTerm` の `t()`)で、設定した呼び方に置き換える
- 責める言葉を使わない(`SPEC.md` 14章①)。医療のアプリではないことの文は、今の「このアプリについて」と同じものを使う(`src/lib/about.ts`)
- 外への通信はしない(ヘルプの文はアプリの中に入れる)

## 1. 「?」ボタンとシート

```
リスト                      [?]   ← 見出しの行の右端
[ToDo][バケット]
...

┌───────────────────────┐
│ ToDo の使い方               │  ← 下から出るシート
│ ・タスクを押すと、やった人を  │
│   選んで記録できます         │
│ ・…                         │
│ [閉じる]                     │
└───────────────────────┘
```

- 見出しの行の右端に「?」ボタンを置く(丸い枠の「?」。読み上げの名前は「この画面の使い方」)
- 押すと、下からシートが出る。見出しは「○○の使い方」、その下に箇条書き、一番下に「閉じる」
- リスト・治療のように、タブの中で画面を切り替えるときは、今出している画面(ToDo/バケット、服薬/受診メモ)のヘルプを出す
- シートを閉じると、元の画面のまま(入力中の内容・スクロール位置は変わらない)
- 「?」を置く画面は確認したいこと1、交代タブの見出しの行は確認したいこと2

## 2. ヘルプの文(案)

「人格」は、表示するときに設定した呼び方に置き換える。

**ToDo の使い方**
- タスクを押すと、やった人格を選んで記録できます。もう一度押すと取り消せます。
- 「今日」「今週」「今月」の欄は、朝5時に切り替わります(週は月曜から)。
- 「期限なし」は、終わるまで残るタスクです。終わったものは「完了済み」にまとまります。
- 「＋ 追加」で期限なしのタスクを、「タスク設定」でほかの周期のタスクを足せます。
- 「並び替え」で、≡ を動かして順番を変えられます。

**バケットの使い方**
- バケットは、人格ごとの「いつかやりたいこと」のリストです。
- 上の名前を押すと、その人格のリストに切り替わります。「+」で人格を足せます。
- リストを変えるときは、そのリストの本人か確かめる文が出ます。
- 叶ったら「叶った」を押すと、「叶ったこと」に移ります。手伝ってくれた人格も残せます。

**服薬の使い方**
- 時間帯ごとに、飲んだ人格を選んで記録します。残りの錠数が自動で減ります。
- 頓服は、飲んだときに理由と一緒に記録できます。
- 「あと何日分」で、残りの目安がわかります。補充したら「残りの錠数」から足せます。
- このアプリは記録のためのものです。薬の量や、飲んでいいかどうかの判断はしません。医師や薬剤師の指示に従ってください。
- データは、この端末の中だけにあります。外には送りません。

**受診メモの使い方**
- 診察で話したいことを、思いついたときに書いておけます。ほかの人格はコメントで書き足せます。
- 話し終えたら「話した?」にチェックを付けます。
- 「診察用の表示」で、まだ話していないメモを、診察で見せやすい形で出せます。交代の記録も一緒に出せます。
- 「受診した」で受診した日を記録すると、「前回の受診日から」の期間に使われます。
- このアプリは記録のためのものです。診断や治療の判断はしません。データは、この端末の中だけにあります。

**交代の記録の使い方**
- 「変わったことに気づいた」を押すと、誰に変わったかを記録できます。どのタブからでも押せます。
- 記録し忘れても大丈夫です。気づいたときに記録すれば、あとから直せます。
- 交代前の人格は、前の記録から自動で入ります。違うときは直せます。
- 月ごとの集計とカレンダーで、傾向を見られます。「受診用にPDF」で書き出せます。
- この記録と集計は、傾向を見るためのものです。診断ではありません。

**診察用の表示の使い方**(決まったこと1で足した画面。文は実装のときに作った案)
- まだ話していないメモを、人格ごと・分類ごとに並べて出します。
- 「メモ+交代記録」にすると、選んだ期間の交代の記録(回数・多いきっかけ・誰から誰に)も出ます。
- 「前回の受診日から」は、「受診した」で記録した日から今日までです。「変える」で基準の日だけ変えられます。
- 「文字としてコピー」で、同じ内容をほかのアプリに貼り付けられます。
- この記録と集計は、傾向を見るためのものです。診断ではありません。

**掲示板の使い方**
- 人格どうしで、話題ごとに書き込んで伝え合えます。データはこの端末の中だけです。
- 「いま見ている人格」は、いちばん新しい交代の記録から決まります。違うときは「変える」で選び直せます。
- まだ見ていない、ほかの人格の書き込みには「● 新着」が付きます。
- 読んだことを伝えたいときは、リアクションの「既読」を付けます。
- 書き込みを直す・消すときは、書いた本人か確かめる文が出ます。

**人格についての使い方**
- 人格の登録・並び替え・非表示ができます。記録のある人格は削除できず、非表示にできます。
- 人格ごとのページに、基本情報やプロフィールを書けます。「早見表」や PDF にもできます。
- 「人格」という呼び方は「呼び方の設定」で変えられます。
- 「バックアップ」で、すべてのデータをファイルに書き出せます。ときどき書き出しておくと安心です。
