# フェーズ1の計画:見た目と画面構成の変更(データは変えない)

## 結論

- 下のタブを [リスト][治療][交代][人格] の4つにする
- 今の画面は作り直さず、置き場所を変えてまとめる。データベース・バックアップの形は一切変えない(データベースの版は 6 のまま)
- 人格の名前を出すところを、色つきの名前ラベル(1つの共通の部品)にそろえる
- 4つの段階に分け、段階ごとに止まって報告する

## 前提

- この計画は、GitHub 上の `main`(8f1399a フェーズ17)のコードを元にしている
- 作業は `dev` ブランチで行い、準備(`docs/plan-setup.md`)が終わってから始める
- 画面の言葉の「人格」は、今と同じしくみ(`useTerm` の `t()`)で、設定した呼び方に置き換える。たとえば呼び方が「メンバー」なら、タブは「メンバー」、見出しは「メンバーについて」になる
- データを変えないので、更新のお知らせはふつうのもの(強めではない)になる

## 今の画面構成(変える前)

- タブ5つ:ToDo/服薬/受診メモ/バケット/人格情報
- 交代の記録は、人格情報タブの「交代の記録を見る」から開く
- 「変わったことに気づいた」ボタンは、どのタブでもタブバーのすぐ上の右側に出ている

## 変えたあとの画面構成

### 1. 下のタブ

- 左から [リスト][治療][交代][人格]
- アイコン
  - リスト:今の ToDo のチェック付きの四角
  - 治療:今の服薬のカプセル
  - 交代:矢印が2つ向かい合う形(新しく描く)
  - 人格:今の人格情報の2人の人
- 今と同じく、タブを切り替えて戻っても、開いていた画面・スクロール位置・入力中の内容は残す

### 2. 「リスト」タブ

```
リスト
┌──────────┬──────────┐
│  ToDo    │ バケット │   ← 切り替えボタン(選んでいる方に色)
└──────────┴──────────┘
          [並び替え][タスク設定]   ← ToDo のときのボタン(今と同じ)
今日
 ...
```

- 一番上の見出しはタブの名前「リスト」にする(今の ToDo の見出し「ひとつやね」は、ここで「リスト」に変わります)
- 見出しの下の切り替えボタンで、[ToDo][バケット] を切り替える
- 切り替えても、それぞれの画面の中身(スクロール位置・選択中・入力中)は残す
- アプリを開いたときは ToDo を出す。アプリを開いている間は、最後に選んだほうを覚えておく
- タスク設定・バケットの項目の編集など、「‹ 戻る」のある画面を開いているときは、切り替えボタンを出さない(戻る先を迷わないように)
- バケットの中身と仕組みは今のまま

### 3. 「治療」タブ

- 見出しは「治療」、その下に [服薬][受診メモ] の切り替えボタン(リストと同じ形)
- アプリを開いたときは服薬を出す
- 服薬の「記録の一覧」「薬の設定」、受診メモの「分類の設定」「診察用の表示」などは今のまま。開いているときは切り替えボタンを出さない

### 4. 「交代」タブ

- 今の「交代の記録」の画面を、そのままこのタブに移す
  - 見出しは「交代の記録」。タブの一番上の画面なので「‹ 戻る」はなくす
  - 月の切り替え・受診用にPDF・集計・記録の一覧・きっかけの設定は今のまま
- 人格タブの「交代の記録を見る」はなくす
- 「変わったことに気づいた」ボタンは、今までどおりどのタブでも出す

### 5. 受診メモの「診察用の表示」

- 人格ごとの見出し(■ 人格A)と、コメントの「└ 人格B:」の名前を、その人格の色の名前ラベルにする
- 「わからない」は灰色のラベルにする
- 「文字としてコピー」の文は今のまま(色は付けられないため)

### 6. 「人格」タブ

```
人格について

<人格の情報>
  (区分ごとの人格の一覧・+ 人格を追加・非表示の人格)

<システム全体について>
  全体のこと ›

┌────────────┬────────────┐
│  人格情報  │  全員分を  │
│   早見表   │  PDF資料に │
└────────────┴────────────┘

<区分と呼び方の設定>
  [区分の設定]
  呼び方(今の選択肢)

集計 / バックアップ / このアプリについて(今のまま)
```

- 画面の見出しは「人格について」
- `<人格の情報>`:今の区分ごとの人格の一覧・「+ 人格を追加」・非表示の人格を、この見出しの下に入れる
- `<システム全体について>`:今の「全体のこと」の入口を、この見出しの下に入れる。入口の文字と、開いた先のページ名・PDF の見出し「全体のこと」は変えない
- 横並びのボタン2つ
  - 「人格情報/早見表」:今の「早見表」と同じ画面を開く
  - 「全員分を/PDF資料に」:今の「全員分をPDFに」と同じ印刷をする
  - `/` の位置で改行する
- `<区分と呼び方の設定>`:今の「区分の設定」の入口と「呼び方」の設定を、この見出しの下にまとめる
- そのあとは今のまま:集計/バックアップ/このアプリについて
- この画面のボタンの文字は、すべて中央揃えにする

### 7. 人格の名前の表示を、色つきの名前ラベルにそろえる

ご依頼の大前提「人格の名前を表示するところは、色の名前ラベルにする」を、このフェーズで今の画面にも当てはめます。

- 名前ラベルの共通の部品を1つ作り、名前を出すところはすべてこの部品を使う
  - 背景がその人格の色、文字はその色の上で読みやすい白か黒を自動で選ぶ(今のラベルは文字がいつも白で、明るい色だと読みにくいため)
  - 「わからない」は灰色のラベル
  - 非表示の人格も、名前と色で同じように出す
- 対象(今、文字の色・小さな丸・ラベルなどで、見た目がばらばらになっているところ)
  - ToDo:やった人格(「人格A・9:12」)・前の期間の表示・気にしている人格
  - 服薬:記録済みの表示・頓服の前回・記録の一覧
  - 受診メモ:一覧のメモとコメントの書いた人格・コメント画面の元のメモ・「人格Aが書いたメモ」の見出し
  - 診察用の表示(5.)
  - バケット:「人格Aのリスト」の見出し・協力してくれた人格
  - 人格について:人格の一覧の行・人格のページの見出し・早見表・集計・「人格Aのページ」の見出し
  - 交代の記録:記録の一覧・集計
- 対象にしないもの
  - 選ぶための部品(記録のときの大きな色のボタン・チェックボックスの横の小さな丸・バケットの人格の切り替えボタン)。今の形のほうが押しやすいため
  - 印刷(PDF)。印刷で背景の色を確実に出すのが難しく、今の見た目で確認が済んでいるため
  - 「時間帯ごと」の色の帯(グラフなので今のまま)

## テスト

- 名前ラベルの文字の色(白か黒か)を決める関数のテスト(明るい色・暗い色・形の正しくない色)
- 今あるテストがすべて通ること(データの処理は変えないので、ほかのテストは変わらない想定)
- 画面の確認(PC の Chrome のデバイスモード)
  - 4つのタブと、リスト・治療の切り替えで、入力中の内容とスクロール位置が残る
  - 呼び方を「メンバー」にしたときに、タブ・見出し・ボタンの言葉が変わる
  - 長い呼び方(10文字)でも、タブとボタンがはみ出さない
  - ダークモードで、名前ラベル・切り替えボタン・「テスト版」の帯が読める

## 決まったこと(2026-10-14)

1. リスト・治療の見出しはタブの名前にし、その下に切り替えボタンを置く。「ひとつやね」の見出しはなくなってよい
2. `<人格の情報>`・`<システム全体について>`・`<区分と呼び方の設定>` は折りたたみにする
   - `<人格の情報>` だけ最初から開いておき、ほかは閉じておく
   - 開け閉めの状態は、アプリを開いている間だけ覚える(保存しない。データの形を変えないため)
3. 名前ラベルにそろえる範囲は、計画のとおり
4. 中央揃えは人格タブのボタンだけ。一覧の行は左揃えのまま。ほかのタブは今回は変えない
5. 「変わったことに気づいた」ボタンは、今までどおり全部のタブに出す
